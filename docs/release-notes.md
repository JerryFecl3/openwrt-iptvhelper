首次签名发行版，面向已验证的 OpenWrt 25.12 / x86_64 部署环境。助手包本身为 noarch，但其他架构尚未进行运行验收。

- 沿用 0.4.0-r6 的业务与界面逻辑，增加 GitHub Actions 构建、签名和 APK 软件源。
- 首次安装默认停用；已有配置与启停状态在升级时保留。
- 升级会通过生命周期脚本停止正在执行的助手任务，再按原启用状态恢复助手服务，可能中断该助手的媒体转发；不重启网络接口、WAN 或 Nikki。
- rtp2httpd 仍为外部依赖，需先安装上游提供的匹配架构安装包。本软件源不包含或重新签名它的包。
- 已通过本地测试不等于在新架构/新运营商上验收，适配范围和安装方法见 README。
